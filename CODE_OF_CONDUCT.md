# Code of Conduct

KubeMemLens follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

This applies to repository discussions, issues, pull requests, reviews, community spaces, and public representation of the project.

## Enforcement

Report conduct concerns privately to the maintainers listed in [MAINTAINERS.md](MAINTAINERS.md) using a private contact method on their GitHub profile. Do not use the public issue tracker for sensitive conduct reports.

Maintainers will handle reports as privately and promptly as practical, avoid conflicts of interest, and may take proportionate action including warnings, content removal, temporary restrictions, or permanent exclusion from project spaces.
